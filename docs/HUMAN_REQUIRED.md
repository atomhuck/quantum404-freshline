# Где нужен человек

Агент делает всё, что может сделать технически. Человек не читает код и не выполняет ручные миграции. Никогда не пересылать секреты в чат/issue/README; вводить через локальный скрытый prompt или приватный `.env` на сервере.

| ID | Действие человека | Когда | Что агент готовит/проверяет |
|---|---|---|---|
| H-01 | Проверить точное время дедлайна и формат отправки 17.10, передать только правила/ссылку | сегодня/13.10 | готовая форма repo URL + product URL + tag/SHA; работа продолжается по внутреннему freeze |
| H-02 | Назначить активных владельцев Orders и Data для T011/T003/T014; подтвердить write-доступ команды и сообщить GitHub usernames, если нужны приглашения | до завершения G0 / согласования T014 | OpenAPI v1.0.0 заморожен (`862949fc902dd441bd24a9e6010917cc60f18b71`); удалённые `codex/orders` и `codex/data` всё ещё `FREE`, миграции и Java port signatures отсутствуют; без владельцев lead не меняет их зоны |
| H-03 | Предоставить доступ к уже имеющемуся VDS: SSH host, user и безопасный способ авторизации; если известны ограничения CPU/RAM/disk/80/443, сообщить | до 15.10 | агент проверяет сервер, Compose, Caddy, firewall, TLS; секреты не публикует |
| H-04 | Дать/утвердить публичный hostname, если уже есть; иначе разрешить временный `sslip.io`-alias на IP | до 15.10 | агент настроит HTTPS и внешний smoke; покупать домен для MVP не обязательно |
| H-05 | Назначить закрытый demo access code и передать его экспертам/жюри вместе с URL по правилам подачи | перед демо | агент настроит ввод вне Git и проверит guest/read/write роли; код не коммитит |
| H-06 | При аварийной передаче сообщить, что прежний агент/ноутбук остановлен, если progress всё ещё ACTIVE | только при аварии | агент делает безопасный takeover и пишет причину |
| H-07 | Принять продуктовое решение, если эксперт изменит бизнес-правила или обнаружится конфликт в ТЗ | только при необходимости | агент приносит конкретные варианты/влияние, вносит ADR и тесты |
| H-08 | Финально открыть продукт с другого устройства и отправить repo URL + HTTPS URL до срока | 16–17.10 | агент проверит links, SHA, demo data, QA и даст короткий текст подачи |

**Домен:** покупать не нужно. Достаточно стабильного HTTPS-имени, например поддомен существующего домена или временный адрес по IP через DNS-alias и сертификат. Свой домен упростит запоминание и сохранит URL после смены IP, но за пять дней не должен блокировать MVP. Если VDS уже используется для прошлого проекта, агент сначала проверит свободные порты и действующий proxy, не нарушая его работу.

**Экспертная сессия:** необязательна, см. `EXPERT_SESSION.md`; отсутствие ответа не останавливает разработку по записанным допущениям.
