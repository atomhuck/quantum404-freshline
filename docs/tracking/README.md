# Таблицы задач по направлениям

Снимок на 15.10.2026. Каждая строка соответствует одному ID из [плана задач](../../specs/001-restaurant-inventory/tasks.md) и [плана своей полосы](../lanes/lead.md). Статус взят из опубликованной ветки соответствующего направления, а не из намерений или локальных файлов другого участника. После нового push владелец направления обновляет свою таблицу вместе с progress; Lead сверяет таблицы при интеграции.

| Направление | Таблица всех пунктов | DONE | Осталось | Готовность по числу пунктов |
|---|---|---:|---:|---:|
| Lead | [20 пунктов](lead.md) | 6 | 14 | 30% |
| Data | [13 пунктов](data.md) | 0 | 13 | 0% |
| Orders | [8 пунктов](orders.md) | 0 | 8 | 0% |
| Web | [12 пунктов](web.md) | 0 | 12 | 0% |
| QA | [10 пунктов](qa.md) | 0 | 10 | 0% |

Формула: `DONE / число пунктов в плане полосы × 100%`; `WIP`, `TODO` и `NOT RUN` не засчитываются. Это доля закрытых пунктов, **не оценка трудозатрат или готовности продукта**. Совместные T014 и T031 присутствуют в планах двух направлений, поэтому при суммировании строк разных полос они считаются дважды. Gate G0–G3 и RELEASE оцениваются отдельно: сейчас ни один не подтверждён.

Источники текущих состояний: [Lead](../progress/lead.md) · [Data](../progress/data.md) · [Orders](../progress/orders.md) · [Web](../progress/web.md) · [QA](../progress/qa.md). Историю фактической передачи ищите в [журналах](../handoffs/README.md). Таблицы опубликованы сначала в `codex/lead`; до интеграции в остальные ветки их копии могут отсутствовать или отставать.
