# FreshLine

**Quantum404 · хакатон «Флагман» · 12–17 октября 2026**

FreshLine — веб-система для ресторанного склада: принимает поставки по партиям, следит за сроком годности, проверяет состав заказа, списывает ингредиенты по FEFO, автоматически показывает стоп-лист и объясняет, какие блюда выгодно предложить сейчас.

> **Состояние:** проектирование завершено; код продукта, развёртывание и приёмка ещё не заявлены. Этот README будет обновлён фактическими ссылкой, SHA и результатами проверок перед сдачей.

## Что увидит жюри в целевом MVP

1. Поставка регистрируется с номером, датой и несколькими партиями. Одинаковый ингредиент в разных поставках имеет собственные остатки и сроки.
2. Экран склада показывает суммарный и партионный остаток, дни до истечения, риск списания и объяснимую рекомендацию докупить.
3. Заказ из нескольких блюд принимается целиком или отклоняется с понятным дефицитом. Успешное списание использует партии с ближайшим сроком годности.
4. Стоп-лист обновляется вслед за поставкой/заказом/истечением срока. Никакое блюдо не обещается, если доступного ингредиента недостаточно.
5. «Горячие предложения» ранжируют доступные блюда по близости срока годности ингредиентов с объяснением причин. Отдельный демо-клиент генерирует поток поставок и заказов.
6. QA показывает конкурирующие заказы, повтор одного запроса, отказ БД и восстановление без отрицательных остатков и двойного списания.

## Технологии

Java 21 · Spring Boot 3.5.16 · PostgreSQL 17 · Flyway · jOOQ/JDBC для точного SQL · React 19 / TypeScript / Vite · Chakra UI 3 · TanStack Query · Docker Compose · Caddy HTTPS. Один Java API-монолит с модулями домена, данных и интерфейса; Python используется только в контейнере синтетического симулятора. Точные версии фронтенд-зависимостей и image digests фиксируются при создании lock-файлов. Подробности: [план](specs/001-restaurant-inventory/plan.md).
